# Social Media Dashboard — CSS Layout Showcase (UI Only)

A CSS-focused project that recreates a social media management dashboard UI.  
This repo exists to demonstrate **modern CSS layout and styling** (Grid, Flexbox, fluid type, responsive patterns). There is **no app logic** or data fetching—React components are used purely for structure.

## Live Demo

Check the Live demo here : [Bento-Grid-WebApp]https://bento-grid-webapp.netlify.app/

## What this is

- A collection of UI sections: Create Post, Social Media header, Schedule to Social, Write Your Content, Manage Accounts, Maintain Schedule, Faster Audience Growth, Grow Followers.
- A single-page composition using **CSS Grid + Flexbox** and modular styles.

## What this isn’t

- No CRUD, API calls, auth, or scheduling logic.
- No interactivity beyond basic layout and styling.

## Tech

- **React** (component structure only)
- **CSS** (Grid, Flexbox, fluid typography, media queries)
- **Google Font:** DM Sans
